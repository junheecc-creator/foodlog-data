# foodlog-data

푸드로그 앱의 재료사전 **월별 시세표**를 배포하는 저장소입니다.

## 파일

- `dict-monthly.json` — 품목 × 월(1~12) 원/kg 중앙값. 앱이 해가 바뀔 때 받아갑니다.

## 출처와 가공

- 원자료: 공공데이터포털 「한국농수산식품유통공사_전국 공영도매시장 정산정보」(katSale)
- 가공: 전국 공영도매시장 33곳 · 특·상 등급 · kg 단위 거래만 · 월별 표본일 중앙값
- 특정 판매처의 가격표가 아니며, 공공자료를 통계 가공한 참고 시세입니다.

## 갱신

연 1회(12월 말) 직전 12개월치로 갱신합니다. `version` 필드(`YYYY-MM`)로 새 표 여부를 판단합니다.
