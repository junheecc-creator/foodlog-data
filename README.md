# foodlog-data

푸드로그 앱이 받아가는 **공공 시세 자료**를 배포하는 저장소입니다.

## 파일

- `dict-monthly.json` — 품목 × 월(1~12) 원/kg 중앙값. 앱이 해가 바뀔 때 받아갑니다.
- `market-daily.json` — 가락시장 **날짜별 경매 결과**(품목 × 등급 × 포장 · 물량·평균·최고·최저). 앱이 날마다 받아갑니다.

## 출처 표시

이 저장소의 자료는 **공공데이터포털(data.go.kr)에서 제공하는 공공데이터를 가공**한 것입니다.

| 파일 | 원자료 | 제공기관 |
|---|---|---|
| `dict-monthly.json` | 전국 공영도매시장 정산정보(katSale) | 한국농수산식품유통공사(aT) |
| `market-daily.json` | 경락가격정보 · 가락시장(110001) | 한국농수산식품유통공사(aT) · 서울특별시농수산식품공사 |
| `weekly.json` | 정산정보(katSale) · 가락시장 주 1회 표본(2021-09~ · 제철 판정의 원자료 · 앱에 직접 안 들어감) | 한국농수산식품유통공사(aT) |
| `wipan-baseline.json` | 위판장별 위탁판매 현황(0040) · 3년 전수를 달×어종 보통 주 물량(kg)으로 접은 기준선(가격 없음 · 앱에 직접 안 들어감) | 해양수산부 |

- 이용조건: 각 데이터셋의 **공공누리 유형**을 따릅니다. 가락시장 경매결과는 공공데이터포털에
  「이용허락범위 제한 없음」으로 공개돼 있습니다.
- 본 저장소는 위 공공데이터를 **가공한 2차 저작물**이며, 원자료의 정확성·최신성은 제공기관에 있습니다.
- 제공기관이 이 저장소를 보증하거나 이 저장소와 제휴한 것은 아닙니다.

## 가공 방법

- `dict-monthly.json` — 전국 공영도매시장 33곳 · 특·상 등급 · kg 단위 거래만 · 월별 표본일 중앙값
- `market-daily.json` — 날짜별로 품목(소분류) × 등급 × 포장으로 묶어 물량 합 · **물량 가중 평균가** ·
  최고 · 최저 · 거래건수를 냅니다. **단위를 환산하지 않습니다**(상자면 상자 값 그대로).
- 특정 판매처의 가격표가 아니며, 공공자료를 통계 가공한 참고 시세입니다.

⛔ 여기에는 앱 사용자의 자료(영수증·재료·레시피·원가)나 인증키가 **들어가지 않습니다.**
공공기관이 이미 공개한 값만 담습니다.

## 갱신

- `dict-monthly.json` — 연 1회(12월 말) 직전 12개월치로 갱신합니다. `version` 필드(`YYYY-MM`)로 새 표 여부를 판단합니다.
- `market-daily.json` — GitHub Actions가 **매일 06:00(KST)** 받아 올립니다(검증 관문을 통과한 경우에만).
